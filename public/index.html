05 / PRACTICAL LIMITS

What stays free

Compute

SQL executes inside DuckDB-Wasm in the visitor's browser. It does not consume Worker CPU.

Local files

Files stay local to the browser session. No upload endpoint is involved.

Remote data

The browser contacts publishers directly first. Catalogue CSV/TSV blocked by CORS can use the complete-file ≤8 MiB relay; larger files stay download/drop only unless direct CORS works.

Engine

DuckDB-Wasm is loaded from jsDelivr on first use, keeping large WASM binaries out of this GitHub repo and Cloudflare assets.
